# Contributing to Archivonchik

Archivonchik should stay focused, small, and practical.

## Principles

- Prefer precise project context over long generic advice.
- Do not add new files unless they improve a workflow.
- Avoid context bloat.
- Keep templates copy-paste ready.
- Do not include secrets, tokens, private keys, or unsafe commands.
- Every new playbook should explain when to use it, how to run it, and what output to produce.

## Pull request checklist

- The change improves AI-readiness, project memory, safety, or workflow quality.
- The README still reflects the repository structure.
- New templates avoid private data and huge logs.
- New instructions do not conflict with existing instructions.
- New command examples classify risk when appropriate.
