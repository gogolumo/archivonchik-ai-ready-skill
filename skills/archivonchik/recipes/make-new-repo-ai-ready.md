# Recipe: Make a New Repository AI-Ready

Prompt:

```text
Use Archivonchik. Make this repository AI-ready.
```

Steps:

1. Inspect repository structure.
2. Detect stack and package manager.
3. Discover commands.
4. Create `AGENTS.md`.
5. Create `CLAUDE.md`.
6. Create `docs/ai-context/` memory files.
7. Run context lint.
8. Produce a short report.
