# Context Lint

Review context files:

- `AGENTS.md`
- `CLAUDE.md`
- `.github/copilot-instructions.md`
- `docs/ai-context/*`

## Checks

- Too long.
- Repeated rules.
- Contradictions.
- Phantom paths.
- Outdated commands.
- Unsafe commands.
- Secrets.
- Missing test instructions.

## Output

Context Health Score and fixes.
