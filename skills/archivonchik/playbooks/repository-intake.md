# Repository Intake

Use this when first entering a project.

## Checklist

- What does the project do?
- What stack does it use?
- How is it run?
- How is it tested?
- What files are generated?
- What files are high-risk?
- What documentation already exists?

## Deliverable

Update `PROJECT_MAP.md`, `ARCHITECTURE.md`, `COMMANDS.md`, and `RISK_ZONES.md`.
