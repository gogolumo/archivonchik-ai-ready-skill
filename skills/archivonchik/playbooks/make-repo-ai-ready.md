# Make Repo AI-Ready

## Steps

1. Inspect root files and directory structure.
2. Detect stack and package manager.
3. Read existing README and docs.
4. Discover commands.
5. Identify risk zones.
6. Create minimal context files.
7. Run context lint.
8. Produce a final report.

## Output

- Files created/updated.
- Commands discovered.
- Risks found.
- Next steps.
