# AI Readiness

A repository is AI-ready when a coding agent can safely and efficiently understand, change, verify, and document the project.

## Minimum requirements

- Clear project overview.
- Known stack and package manager.
- Build, test, lint, and dev commands.
- Risk zones and files to avoid.
- Coding conventions.
- Security rules.
- Current state and next steps.
- Known bugs and decisions.
- Safe command policy.

## AI-ready does not mean huge context

Large context files can hurt performance. Keep instructions short, current, and specific.
