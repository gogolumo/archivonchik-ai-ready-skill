# CLAUDE.md

`CLAUDE.md` gives Claude Code project-specific instructions.

## Recommended content

- Startup behavior.
- Files to read first.
- Command safety rules.
- Project memory paths.
- Verification expectations.
- When to ask for confirmation.

## Startup example

```md
At the start of each session:
1. Read docs/ai-context/CURRENT_STATE.md.
2. Read docs/ai-context/NEXT_STEPS.md.
3. Read docs/ai-context/DO_NOT_TOUCH.md.
4. Summarize the project state before editing.
```
