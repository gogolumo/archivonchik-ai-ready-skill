# Project Memory

Project memory is durable context stored in repository files.

## Store

- Current project state.
- Next steps.
- Architecture decisions.
- Known bugs.
- Active tasks.
- Do-not-touch files.
- Conventions.
- Glossary.

## Do not store

- Secrets.
- Personal data.
- Full chat logs.
- Full terminal logs.
- Temporary confusion.
- Large code copies.

## Update policy

Only update memory when the information will help future sessions.
