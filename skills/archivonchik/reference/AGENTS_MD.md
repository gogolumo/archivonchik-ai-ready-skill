# AGENTS.md

`AGENTS.md` is the general instruction file for coding agents.

## Recommended sections

- Project overview.
- Setup commands.
- Build/test/lint commands.
- Code style.
- Testing expectations.
- Security considerations.
- Files to avoid.
- PR expectations.

## Rules

- Keep it concise.
- Use real commands from the repository.
- Do not duplicate the entire README.
- Do not include secrets.
- Keep agent-only details out of human README.
